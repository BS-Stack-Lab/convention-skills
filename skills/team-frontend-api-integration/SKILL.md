# 프론트엔드 API 통합

작업 전에 [프론트엔드 컨벤션 원문](../team-frontend-conventions/references/frontend-convention-original.md)의 `### 3. API 및 데이터 통신 규칙` 전체와 `### 7. 추가 규칙` 중 API·응답·환경 변수·보안 정보 관련 항목을 읽는다.

원문 기준으로 API 계약, 사용자 메시지, 환경 변수, 비밀 정보, 호환성, PR 영향 범위를 처리한다.

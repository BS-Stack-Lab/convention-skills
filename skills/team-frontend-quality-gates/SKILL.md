# 프론트엔드 품질 게이트

작업 전에 [프론트엔드 컨벤션 원문](../team-frontend-conventions/references/frontend-convention-original.md)의 `### 5. 테스트 및 CI/CD` 전체를 읽는다.

원문에 정의된 Prettier·ESLint 설정, npm 스크립트, lint-staged, 테스트 범위, 로컬 검증, CI/CD, Git Hook 규칙을 그대로 적용한다. 실행하지 못한 검증은 수행한 것처럼 기록하지 않는다.

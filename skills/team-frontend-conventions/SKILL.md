# 프론트엔드 컨벤션 라우터

이 스킬은 프론트엔드 작업의 관련 규칙을 고르는 용도다. 컨벤션 원문은 [frontend-convention-original.md](references/frontend-convention-original.md)에 원문 그대로 보관한다.

- 컴포넌트, Hook, TypeScript, JSX, Prettier, ESLint 작업은 `team-frontend-code-style`을 사용한다.
- REST API 호출, 응답 타입, 오류 처리, Vite 환경 변수 작업은 `team-frontend-api-integration`을 사용한다.
- 브랜치 생성, 커밋 작성, Breaking Change 검토는 `team-frontend-git-workflow`를 사용한다.
- 포맷·린트·테스트·빌드·CI/CD·Git Hook 작업은 `team-frontend-quality-gates`를 사용한다.
- PR, 코드 리뷰, 병합, 보안 정보 마스킹, 배포 전 확인은 `team-frontend-review-governance`를 사용한다.

여러 영역을 바꾸면 해당하는 모든 세부 스킬을 적용한다. 세부 스킬이 원문을 읽기 전에는 요약이나 기억에 의존해 규칙을 추정하지 않는다.

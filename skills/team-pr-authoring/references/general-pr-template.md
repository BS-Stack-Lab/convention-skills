# 일반 PR 템플릿

```markdown
## 작업 내용 / 이슈
- 관련 이슈: Closes #
- 작업 목적:

## 변경 요약
- 변경 전:
- 변경 후:

## 영향 범위
- 영향받는 기능 또는 화면:
- API / DB / 외부 연동:
- 영향 없음:

## 체크리스트
- [ ] 하나의 목적에 집중된 PR입니다.
- [ ] 필요한 테스트를 추가·수정하고 실행했습니다.
- [ ] 민감 정보, 디버그 코드, 불필요한 파일이 포함되지 않았습니다.
```

작성 시 관련 이슈는 `Closes #번호`로 연결한다. 이슈가 없으면 해결할 사용자·운영상 문제를 한두 문장으로 쓴다.

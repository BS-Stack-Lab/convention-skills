# 이슈·PR·커밋 제목 규칙

GitHub 이슈, Pull Request, Git 커밋의 제목을 작성·수정·검토할 때 사용한다. 이 팀에서는 제목을 동사 문장이나 명령형으로 끝내지 않고, 변경 결과를 나타내는 명사형 구로 작성한다.

작성 전에 [명사형 제목 가이드](references/noun-phrase-title-guide.md)를 읽는다.

- 기존 원문 컨벤션의 제목 형식, 타입, Scope, 길이, Breaking Change 규칙은 유지한다.
- 사용자 요청에 따라 원문의 한국어 문장형 허용 표현보다 이 명사형 규칙을 우선한다.
- 이 규칙은 제목에만 적용한다. 본문은 변경 이유·배경·영향을 자연스러운 문장으로 작성한다.

# 프론트엔드 코드 스타일

작업 전에 [프론트엔드 컨벤션 원문](../team-frontend-conventions/references/frontend-convention-original.md)의 `### 1. 코드 컨벤션 (Prettier & ESLint)` 전체를 읽는다.

원문에 있는 네이밍 규칙, 예시, Prettier 설정, ESLint 설정을 그대로 적용한다. 원문에 없는 스타일 규칙을 팀 규칙처럼 추가하지 않는다.

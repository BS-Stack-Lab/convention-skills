# 프론트엔드 PR·리뷰 운영

작업 전에 [프론트엔드 컨벤션 원문](../team-frontend-conventions/references/frontend-convention-original.md)의 `### 6. PR 및 코드 리뷰`와 `### 7. 추가 규칙` 전체를 읽는다.

PR 본문을 작성·수정·리뷰하면 `team-pr-authoring`도 함께 사용한다. 원문에 정의된 PR 병합, 리뷰 승인, API 문서, 배포 확인, Feature Flag, 롤백, 민감 정보 마스킹 기준을 그대로 적용한다.
